A practical starting point

Make the devices you own useful infrastructure.

Pocket Host is a mobile-first personal infrastructure platform. The first milestone focuses on a dependable Android static website host. The wider vision connects separate devices through explicit identity, owner approval and bounded roles.

⌂

Host from Android

Import a website folder or ZIP and serve HTML, CSS, browser JavaScript and static assets from your phone.

◎

Local and LAN access

Preview on the phone and optionally let devices on the same Wi-Fi network reach your site.

↗

Bring your own domain

Optional public ingress paths include Cloudflare Tunnel and the native Relay direction. Public access depends on network reachability and completed setup.

▤

Website workspace

Manage imported sites and their files. The fuller editing, preview and publishing workflow is planned for v0.1.1.

⌘

Optional runtimes

Python and Node.js companion foundations exist. Their complete acceptance is assigned to v0.1.1; static hosting does not depend on them.

⬡

Connected devices

A future device fabric will use explicit enrollment, signed grants, revocation and limited worker roles — not automatic trust.

One product · Two operating modes

Hosting stays on. You choose how much to manage.

The two-mode rule is fundamental: both modes include website serving. There is no Command Center-only mode.

MODE 01

Server Only

Keep the phone focused on serving websites.

  • Import and manage static websites
  • Local preview and optional LAN hosting
  • Hosting controls and diagnostics
  • No fleet administration surface
MODE 02

Command Center + Server

Serve websites and administer your verified device fabric from the same phone.

  • Everything in Server Only
  • Device enrollment and owner approval
  • Bounded roles and device administration
  • Connected-fabric capabilities mature in v0.1.2
The first hosting journey

From a website folder to your own hosted site.

Built around a simple static-site path. A pre-built React/Vite site can be hosted from its output folder; v0.1.0 does not compile raw TypeScript projects on the phone.

Bring your website

Import a folder or ZIP containing your built HTML, CSS, JavaScript and assets. Defined import limits protect device resources.

Choose where it serves

Preview locally, enable same-network access when needed, or configure an optional public ingress path and your domain.

Stay in control

Use the hosting service controls, diagnostics and recovery features. Public deployment still needs real network and device verification.

A deliberate release path

Three milestones. One expanding platform.

These are roadmap targets, not claims that every capability is already complete or released.

FIRST HOSTING
v0.1.0

Android Website Hosting

Static website import, local preview, LAN serving, public-domain ingress paths, hosting lifecycle, backup/restore and Android acceptance.

WORKBENCH & RUNTIMES
v0.1.1

Build and publish

Private drafts, isolated preview, diffs, TypeScript build, approved publishing and rollback; complete optional Python/Node integration and Linux Relay installation.

CONNECTED DEVICE FABRIC
v0.1.2

Connect your devices

Explicit enrollment, signed role grants, revocation, bounded workers, authenticated coordination and multi-host Relay/failover.

Designed with boundaries

Local-first. Modular by design.

The architecture separates the Android host, static website engine, optional ingress, runtime companion and future device control plane. Each piece has a defined responsibility.
