# Pocket Host Assets

This directory contains first-party visual assets used by **AssayFlux Pocket Host**.

Keep source files here organised by purpose. Prefer descriptive filenames, preserve editable originals where practical, and document the source and licence of every third-party asset before bundling it.

## Suggested structure

- `branding/` — approved Pocket Host and AssayFlux marks, app icon source artwork, wordmarks.
- `screenshots/` — current application screenshots used in documentation.
- `illustrations/` — original product illustrations and diagrams.
- `animations/` — approved splash or instructional animations.
- `README.md` — asset inventory and attribution notes.

## Asset rules

1. Use only artwork created for Pocket Host or assets with documented permission and compatible licences.
2. Do not copy Kinetics project artwork into this repository; use it only as a visual-quality reference.
3. Keep app icons, splash artwork and in-app UI resources in their Android resource locations when required by the build.
4. Use optimised formats and reasonable dimensions for mobile distribution.
5. Record the author, source, licence, intended use and any required attribution for externally sourced assets.
6. Do not add generated placeholder logos or screenshots that could be mistaken for finished product artwork.

The directory is intentionally initialised without placeholder imagery. Add approved assets as they are created.
