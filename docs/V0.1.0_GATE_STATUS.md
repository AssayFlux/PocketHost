## Release stop rule

Do not tag v0.1.0, publish a production release or mark any gate PASS until all ten gates have reproducible evidence for the accepted source SHA and artifacts, the named physical-device matrix and independent external-network journeys have passed, and the owner has explicitly approved the release. The stop rule in [RELEASE_GATES.md](RELEASE_GATES.md) is authoritative.
